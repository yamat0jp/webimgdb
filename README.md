# webimgdb

本番環境にイメージファイルを追加していくという危険なつくりになっています。

良いところはシンプルなところです。

imgフォルダの中に自分用のフォルダを作って写真やイラストを保存すれば

ウェブに公開できます。実際にはDelphi CEでコンパイルしてあるので

プライベートネットワークで運用することになるはずです。

最新版のコミュニティエディションでコンパイルできます。

Githubにゴミの山がたまっていく様子を見て仕様書は書かれなければだめだと

思っていた時期がありますが、アップルがそうであるように説明の必要が

ない商品をつくりだすのがエレガントでソフトウェアも脱仕様書の時代が

とっくに来ていた、だから複雑でなくても市場で評価されるソフトウェアが

あるということですね。
